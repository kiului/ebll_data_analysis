# EBLL Housing Risk Analysis

This project analyzes the relationship between housing age and elevated blood lead levels (EBLL) in children using U.S. public health and census data.

## Objective
Evaluate whether older housing stock is associated with higher EBLL incidence and identify risk patterns across regions.

## Methods
- Cleaned and joined housing, demographic, and public health datasets using Python
- Performed exploratory and comparative analysis
- Generated visualizations to surface trends and risk thresholds

## Main Tools
- Python (pandas, matplotlib, seaborn, numpy, scipy)
- Public health & census datasets

## Outputs
- Raw Data
- Data analysis scripts
- Visualizations
- Final written report summarizing methodology and findings
